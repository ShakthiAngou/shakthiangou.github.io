Microgrid Energy Management System (EMS)

Long-term goal: develop an intelligent energy management system for decentralised microgrids in rural India, supporting reliable access to renewable energy.
  • Built a modular microgrid Energy Management System (EMS) simulation for solar generation, load demand, supercapacitor storage, and hydrogen storage.
  • Implemented rule-based dispatch logic that prioritises short-duration storage before hydrogen conversion and tracks system energy flows over 24-hour scenarios.
  • Developed a Matplotlib dashboard for storage state of charge, hydrogen inventory, generation, demand, and post-storage energy balance, establishing a foundation for forecast-aware MPC.
  • Future versions will work towards hardware-in-the-loop testing and ML-based predictive state estimation to support more adaptive energy management.

SightMate: Automated Navigation System

Wearable assistive navigation system for visually-impaired users, combining real-time obstacle detection with spatial audio feedback for safe, hands-free mobility.
  • Built a multi-sensor perception stack (ultrasonic + IMU) on NVIDIA Jetson for low-latency obstacle detection and distance estimation
  • Designed audio-based guidance logic to convey direction and proximity without overwhelming the user

Fractal Tree Based Metadata Indexing for Object Storage

Designed and implemented an in-memory fractal tree–based metadata index to reduce lookup overhead and improve partial read performance in a production S3-compatible object storage system.
  • Implemented a fractal tree data structure to aggregate and organise object metadata in memory, reducing repeated traversal during read operations
  • Analysed performance trade-offs against existing indexing approaches and proposed a hybrid strategy for future production integration
  • Project recognised for technical excellence and impact, resulting in a full-time return offer.
