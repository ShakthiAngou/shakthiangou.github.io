Capstone Project · May 2024

SightMate

A wearable assistive navigation system for visually impaired users, combining real-time obstacle detection with spatial audio feedback for safe, hands-free mobility.

Presentation Report

Purpose

SightMate explores how wearable sensing and intuitive audio guidance can support independent navigation. The capstone focused on communicating nearby obstacles without requiring a handheld interface or overwhelming the user with feedback.

System

Ultrasonic Sensing

Detects nearby obstacles and provides distance information to the perception stack.

Inertial Measurement

Uses IMU data to support awareness of the wearable system's motion and orientation.

Embedded Compute

Runs the low-latency perception pipeline on an NVIDIA Jetson platform.

Spatial Audio

Conveys obstacle direction and proximity through hands-free audio guidance.

Implementation

  • Combined ultrasonic and IMU inputs in a multi-sensor perception stack.
  • Processed sensor data on NVIDIA Jetson for low-latency obstacle detection and distance estimation.
  • Designed guidance logic to communicate direction and proximity without overwhelming the user.

Capstone Deliverables

The project presentation and final report document the system design, implementation, and capstone work.
